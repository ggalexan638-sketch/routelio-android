# Routelio Android

Native Android-App für [Routelio](https://weltreise-planer.ggalexan638.chatgpt.site).

## APK herunterladen

1. Oben **Actions** öffnen.
2. Den neuesten Lauf **Routelio APK bauen** öffnen.
3. Unter **Artifacts** auf **Routelio-APK** klicken.
4. ZIP entpacken und `app-debug.apk` auf dem Android-Handy installieren.

Die App öffnet Routelio in einem eigenen App-Fenster ohne Chrome-Bedienleiste.
